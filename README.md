## 定制改动点

- **屏蔽的吧管理**：支持列表查看、解除屏蔽、排序、搜索与加载全部。
- **显示与隐藏设置组**：导航栏逐项隐藏，动态标签支持开关。
- **图片查看增强**：返回键退出图片、赞数排序、复制全部、推荐流整页刷新。
- **楼中楼显示图片**：帖子页的楼中楼预览在文字下方显示图片缩略图（最多 3 张，超出显示数量），点开进入图片查看器。
- **帖子菜单防误触**：更多菜单只在完全展开后响应点击，菜单滑动过程中落在「收藏」上的误触不再生效。
- **本地构建环境适配**：依赖走国内镜像、离线 SDK、关闭 lint，适配受限网络下的本地编译。
